# Sky Work — ระบบติดตามงาน HR

เว็บแอปส่วนตัวสำหรับติดตามงาน งบประมาณ และปฏิทินงาน
เปิดได้ทั้งมือถือ แท็บเล็ต และโน้ตบุ๊ก ข้อมูลซิงก์อัตโนมัติทุกเครื่อง ติดตั้งลงหน้าจอได้เหมือนแอปจริง (PWA)

## ขั้นที่ 1 — สร้างฐานข้อมูลบน Supabase (ฟรี)

1. เข้า **supabase.com** → Sign in ด้วย Google
2. **New project**
   - Name: `sky-work`
   - Database Password: ตั้งเอง (จดเก็บไว้)
   - Region: **Southeast Asia (Singapore)**
   - กด **Create new project** แล้วรอ ~2 นาที
3. เมนูซ้าย → **SQL Editor** → **New query**
4. เปิดไฟล์ `supabase/schema.sql` ก๊อปทั้งหมด วางลงไป → กด **Run**
   ต้องขึ้น `Success. No rows returned`
5. เมนูซ้าย → **Project Settings** (รูปเฟือง) → **API**
   เก็บ 2 ค่านี้ไว้ใช้ในขั้นที่ 3
   - **Project URL** → หน้าตาแบบ `https://xxxxxxxx.supabase.co`
   - **anon public** key → ข้อความยาวขึ้นต้นด้วย `eyJ...`

> anon key เปิดเผยได้ ไม่ใช่ความลับ เพราะ Row Level Security ล็อกให้เห็นเฉพาะข้อมูลของบัญชีที่ล็อกอินเท่านั้น
> **ห้ามใช้** `service_role` key เด็ดขาด

### (ทางเลือก) ปิดการยืนยันอีเมล เพื่อให้สมัครแล้วเข้าใช้ได้ทันที

**Authentication → Sign In / Providers → Email** → ปิด **Confirm email** → Save

## ขั้นที่ 2 — อัปโหลดขึ้น Vercel

**วิธี A — ลากไฟล์ (ง่ายสุด ไม่ต้องใช้ GitHub)**

1. เข้า **vercel.com** → Sign in ด้วย Google
2. **Add New… → Project → Deploy** (หรือหน้า vercel.com/new)
3. ลากโฟลเดอร์ **`public`** ทั้งโฟลเดอร์ไปวาง
4. กด **Deploy** รอสักครู่ จะได้ลิงก์ `https://xxxx.vercel.app`

**วิธี B — ผ่าน GitHub (อัปเดตง่ายกว่าในระยะยาว)**

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดโฟลเดอร์ `sky-work` ทั้งชุด
2. Vercel → **Add New → Project → Import Git Repository** → เลือก repo นี้
3. ตั้งค่าตอน Import
   - Framework Preset: **Other**
   - Root Directory: **`.`** (ค่าเริ่มต้น)
   - Output Directory: **`public`**
4. กด **Deploy**

## ขั้นที่ 3 — เปิดใช้งานครั้งแรก

1. เปิดลิงก์ Vercel ที่ได้มา
2. หน้าแรกจะถามค่าเชื่อมต่อ ใส่ **Project URL** และ **anon public key** จากขั้นที่ 1 → กด **เชื่อมต่อ**
3. ใส่อีเมลและรหัสผ่านที่จะใช้ล็อกอิน (อย่างน้อย 6 ตัว) → กด **สมัคร / เข้าสู่ระบบ**
   ครั้งแรกระบบจะสร้างบัญชีให้เอง ครั้งต่อไปเครื่องจะจำไว้ ไม่ต้องล็อกอินซ้ำ
4. เข้าเมนู **ตั้งค่า → นำเข้า CSV** → เลือกไฟล์ `data/skywork-tasks-v4.csv` → งานเดิม 60 รายการเข้าระบบทันที

ทำขั้นที่ 3 ซ้ำอีกครั้งบนเครื่องที่สอง (ใส่ URL + key + ล็อกอินด้วยอีเมลเดิม) จะเห็นข้อมูลชุดเดียวกัน

### อื่นๆ ที่เพิ่มมา
- **ป้ายกำกับ + สี 16 สี** ในทุกฟอร์มเพิ่มงาน — จุดสีในปฏิทินเดือน/ปี ใช้สีที่เลือก
- **ย้ายงานยกชุด** — ตั้งค่า → กลุ่มงาน/บริษัท กดตัวเลขจำนวนงานเพื่อดู กดปุ่มลูกศรเพื่อย้ายทั้งหมด
- **ชิปสถานะสีแดง กดดูสาเหตุได้** เมื่อบันทึกไม่สำเร็จ
- **ปฏิทินทั้งปีแยกหมวด** อบรม/ประชุม/โปรเจค/กิจกรรม/อื่นๆ พร้อมเลือกปี

### เตือนงานใกล้ครบกำหนด

- หน้าภาพรวมขึ้นแถบเตือนเองเมื่อมีงานเลยกำหนด ครบกำหนดใน 7 วัน หรือถึงวันที่ต้องเริ่มเตรียมข้อมูลก่อนประชุม
- การประชุมใส่ **เตรียมข้อมูลล่วงหน้า (วัน)** ได้ ระบบนับถอยหลังจากวันประชุมให้เอง ใช้ได้กับประชุมที่ตั้งเกิดซ้ำด้วย (นับจากรอบถัดไปเสมอ)
- **ตั้งค่า → เตือน & ปฏิทิน** เปิดการแจ้งเตือนของเบราว์เซอร์ได้ (เด้งวันละครั้งเมื่อเปิดแอป ถ้ามีงานครบกำหนดใน 2 วัน)
- ปุ่ม **ดาวน์โหลดไฟล์ปฏิทิน (.ics)** รวมงานทั้งหมดรวมงานที่ตั้งเกิดซ้ำล่วงหน้า 14 เดือน พร้อมเตือนล่วงหน้า 2 วัน และสร้าง event **[เตรียมข้อมูล]** แยกให้ตามจำนวนวันที่ตั้งไว้ นำเข้า Google Calendar ได้เลย (Settings → Import & export → Import)

ทุกหน้ามีตัวกรอง **รายปี / รายเดือน / รายสัปดาห์**

## รูปแบบไฟล์ CSV สำหรับนำเข้า

บรรทัดแรกต้องเป็นหัวคอลัมน์ (สลับลำดับได้ ขาดคอลัมน์ไหนก็ได้ ยกเว้น **ชื่องาน**) บันทึกเป็น **CSV UTF-8**

```csv
ชื่องาน,กลุ่ม,ประเภท,สถานะ,ผู้รับผิดชอบ,วันที่,บริษัท,หมวด GL,งบ,ใช้จริง,เวลา,สถานที่,ผู้เข้าร่วม,เตรียมล่วงหน้า(วัน),สิ่งที่ต้องเตรียม,ผู้เข้าอบรม,ชั่วโมง,วิทยากร/สถาบัน,กรมพัฒฯ,การเกิดซ้ำ,รายละเอียด
อบรมดับเพลิงขั้นต้น,อบรมตามกฎหมาย,อบรม,รอดำเนินการ,วิม,2026-07-16,LeKise (LKL),781800000 ค่าฝึกอบรม,37800,0,,,,,,120,6,สถาบันความปลอดภัย,รอยื่น,,จองวิทยากรแล้ว
One HR Meeting,งานประจำเดือน,ประชุม,รอดำเนินการ,วิม,2026-09-17,LeKise (LKL),,0,0,10:00,ห้องประชุมใหญ่,HR ทั้งกลุ่ม,5,สรุปภาพรวม HR ทุกบริษัท,,,,,ทุกพฤหัสที่ 3,
```

- **วันที่** รูปแบบ `ปี-เดือน-วัน` เช่น `2026-07-16` (เว้นว่างได้ถ้าเป็นงานประจำ)
- **สถานะ** ใช้ได้ 3 แบบ: `รอดำเนินการ` / `กำลังดำเนินการ` / `เสร็จสิ้น`
- **กลุ่ม** และ **บริษัท** ถ้าไม่ตรงกับที่มีอยู่ ระบบจะสร้างให้ใหม่อัตโนมัติ
- **หมวด GL** ใส่ได้ทั้ง `781800000 ค่าฝึกอบรม` หรือชื่อหมวดอย่างเดียว ถ้ายังไม่มีระบบจะสร้างหมวดให้อัตโนมัติ
- **ผู้เข้าอบรม / ชั่วโมง / วิทยากร/สถาบัน / กรมพัฒฯ** ใส่เฉพาะงานอบรม · กรมพัฒฯ ใช้ได้: `ไม่ต้องยื่น` / `รอยื่น` / `ยื่นแล้ว` / `อนุมัติแล้ว` / `ไม่ผ่าน`
- กลุ่มที่มีคำว่า **อบรม** ระบบจะนับเป็นงานฝึกอบรมและขึ้นในหน้าฝึกอบรมอัตโนมัติ
- **เวลา / สถานที่ / ผู้เข้าร่วม / เตรียมล่วงหน้า(วัน) / สิ่งที่ต้องเตรียม** ใส่เฉพาะการประชุม (ชื่อหรือประเภทที่มีคำว่า "ประชุม" ระบบนับเป็นการประชุมอัตโนมัติ)
- **การเกิดซ้ำ** เขียนเป็นภาษาไทยได้เลย: `ทุกวัน` · `ทุกอังคาร` · `ทุกพฤหัสที่ 3` · `ทุกศุกร์ที่ 1 และ 3` · `ทุกวันที่ 10` · `ทุกปี`
- การนำเข้าจะ **เพิ่มต่อท้ายเสมอ** ไม่ลบของเดิม (ล้างก่อนได้ที่ ตั้งค่า → การเชื่อมต่อ → ล้างข้อมูล)
- ถ้าหัวคอลัมน์แรกเป็น **ชื่อรายการ** ระบบจะถือว่าเป็น **ทะเบียนกฎหมาย/ใบรับรอง** และนำเข้าไปที่เมนู "กฎหมาย" ให้เอง

## สำรองข้อมูล

**ตั้งค่า → การเชื่อมต่อ → ดาวน์โหลดงานเป็น CSV** (และรายการเงิน) แนะนำให้ทำเดือนละครั้ง

## ล้างข้อมูลเพื่อนำเข้าใหม่

**ตั้งค่า → การเชื่อมต่อ → ล้างข้อมูล** มีปุ่มล้างงานทั้งหมด และล้างรายการเงิน
ต้องพิมพ์รหัสยืนยันที่ระบบสุ่มจากจำนวนรายการ (เช่น `ลบ60`) จึงจะลบได้ กันกดพลาด
การตั้งค่าทั้งหมด (กลุ่มงาน บริษัท หมวด GL ธีมสี) **ไม่ถูกลบ** ลบเฉพาะข้อมูลงาน/รายการเงิน
ดาวน์โหลด CSV เก็บไว้ก่อนทุกครั้ง เพราะลบแล้วกู้คืนไม่ได้

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| ค้างที่ "กำลังโหลด…" | URL หรือ anon key ผิด — ล้างค่าแล้วใส่ใหม่ที่ Console: `localStorage.clear()` แล้วรีเฟรช |
| สมัครแล้วเข้าไม่ได้ | ยังไม่ได้ปิด Confirm email ในหน้า Authentication หรือยังไม่ได้กดยืนยันในอีเมล |
| บันทึกแล้วขึ้น "บันทึกไม่สำเร็จ" | ยังไม่ได้รัน `schema.sql` หรือ RLS policy ไม่ถูกสร้าง — รันสคริปต์ซ้ำอีกครั้ง |
| แก้จากมือถือแล้วโน้ตบุ๊กไม่อัปเดต | ยังไม่ได้เปิด Realtime — รันบรรทัด `alter publication supabase_realtime add table public.rows;` |
| อัปเดตเว็บแล้วยังเห็นของเก่า | Service worker แคชไว้ — ปิดแท็บทั้งหมดแล้วเปิดใหม่ หรือ Hard refresh |

## หมายเหตุทางเทคนิค

- ไม่มี build step — เป็น static HTML/CSS/JS ล้วน
- โครงข้อมูล: ตาราง `rows` เดียว แยกด้วยคอลัมน์ `kind` (`items` = งาน, `ledger` = รายการเงิน, `meta` = การตั้งค่า) เก็บเนื้อหาใน `data` แบบ JSONB
- เปลี่ยนโครงข้อมูลภายหลังไม่ต้อง migrate ตาราง
- โควตาฟรีของ Supabase (500MB) รองรับข้อมูลระดับนี้ได้หลายปี

## ผู้ช่วย AI (v14.1)

หน้า **ผู้ช่วย AI** มี 2 โหมด
1. **คัดลอก–วาง** (ใช้ได้ทันที ไม่ต้องมี key): พิมพ์คำถาม → แอปคัดลอก “ข้อมูลในระบบ + คำถาม” ให้ → ไปวางในแชท Claude ปกติ → ก๊อปคำตอบกลับมาวาง
2. **ฝังในแอป**: ใช้ไฟล์ `api/ai.js` (Vercel Serverless Function) เก็บ API key ไว้ฝั่งเซิร์ฟเวอร์เท่านั้น

เปิดโหมดฝังในแอป: Vercel → Settings → Environment Variables
- `ANTHROPIC_API_KEY` — สร้างที่ console.anthropic.com (เสียค่าใช้จ่ายตามการใช้งาน แยกจากแพ็กเกจแชท)
- `SUPABASE_URL` และ `SUPABASE_ANON_KEY` — ค่าเดียวกับที่ใช้ตอนตั้งค่าแอป (anon/publishable key เท่านั้น)
- (เสริม) `ALLOWED_EMAILS` จำกัดอีเมลที่ใช้ได้ · `AI_MODEL` ระบุชื่อรุ่นโมเดล

แล้ว Redeploy · **ห้ามใส่ API key ใน app.js หรือวางในแชท** · ห้ามใช้ service_role key
AI เสนอการแก้เป็นการ์ด (เปลี่ยนสถานะ/เลื่อนวัน/มอบหมาย/เพิ่มงาน/เพิ่มบันทึก) ต้องกด “ทำตามนี้” เองทุกครั้ง และไม่มีการลบข้อมูล
